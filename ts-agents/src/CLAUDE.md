# Claude AI Agent

## 项目概述

这是一个基于 TypeScript 的 Claude AI Agent 项目，展示了如何使用 Claude API 构建智能代理系统。

## 项目结构

```text
ts-agents/
├── configs/           # 配置文件
│   └── systemConstant.ts
├── tools/            # 工具集
├── utils/            # 工具类
├── index.ts          # 入口文件
├── ts01_agent_loop.ts    # Agent 循环逻辑
└── ts02_tool_use.ts      # 工具使用示例
```
